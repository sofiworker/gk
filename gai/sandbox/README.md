# Sandbox

[English](README.en.md)

开发中，禁止直接用于生产开发。SDK 内置 `memory` 实现是进程内环境，文件、内容版本、审计、快照与同步进度均保存在内存中，不启动子进程，不隐式创建宿主目录或网络连接。

## 包与能力

| 包 | 用途 |
| --- | --- |
| `sandbox` | 文件、网络、审计、快照、同步等小接口与稳定错误的领域入口；共享定义位于 core |
| `sandbox/memory` | 内存环境、资源绑定、访问检查、工具能力视图、资源申请 |
| `sandbox/local` | 显式宿主目录导入、根句柄约束的冲突检测与写回 |
| `sandbox/httpgate` | 显式授权的 HTTP/HTTPS 出口、凭据注入与请求限制 |

不依赖第三方 Sandbox 或数据库。创建时只有虚拟根目录 `/`，默认允许操作纯内存文件；外部资源和网络默认不可用。目录名称由调用方决定，不代表权限或用途。`WithAccess` 设置纯内存区域的访问规则，外部绑定使用各自的 `Access`。

## 使用方式

```go
ctx := context.Background()
box, err := memory.New(memory.WithID("session-42"))
if err != nil {
    return err
}
if _, err = box.Mkdir(ctx, sandbox.Call{}, "/project-a"); err != nil {
    return err
}
view := box.View(sandbox.Call{
    Dir: "/project-a", SessionID: "42", TurnID: "1", ToolCallID: "tool-1",
})
result, err := view.WriteFile(ctx, sandbox.Call{ID: "write-1"}, "hello.txt", []byte("hello"))
```

`View` 只暴露文件、HTTP 和资源申请方法，不暴露提供资源、修改规则、快照恢复或销毁等管理能力。它固定执行归属和工作目录，文件与网络接口可以分别注入 `core.ToolContext`。可信 Runtime 仍须按 Agent 工具列表和应用策略选择实际注入的接口；View 不是对任意 Go 回调的隔离。

所有文件操作是整文件级操作。创建目录不递归；删除目录递归，但禁止通过文件操作删除资源绑定根及其祖先；重命名不覆盖现存目标，也不跨资源绑定。相对路径使用本次 `Call.Dir` 或默认工作目录，绝对路径基于虚拟根；不会改变宿主 cwd。不支持链接、设备文件、可写句柄或原生命令。

文件修改可携带稳定 `Call.ID`，同一 ID 与相同请求返回原结果；不同请求返回 `ErrConflict`。返回值的 `LocalApplied` 表示内存变更是否已接受，`SyncState` 独立描述写回结果。幂等记录保留到环境销毁；达到 Operations 配额后拒绝新修改。重试同步应调用 `Sync`，不要重跑 Agent 操作。

## 导入与同步

调用 `local.Import(ctx, hostDir, limits)` 取得固定目录副本，再用 `Provide` 设置资源 ID、任意虚拟目标路径、访问规则及可选 Target。目标路径的父目录须先存在，目标本身须不存在。普通目录导入要求调用方保证一致视图，拒绝符号链接、硬链接及特殊文件。

- `SyncNone`：不提供 Target，变更只在内存中。
- `SyncExplicit`：通过 `Sync(ctx, resourceID)` 写回，适合由应用在 Turn 或 Session 明确完成时调用。
- `SyncImmediate`：先接受内存修改，再等待同步；失败仍保留内存修改。

绑定可写回时，以导入内容作为宿主预期基线。每批固定目标版本，按目录深度安排删除与创建；重命名展开为文件变化。部分失败保留成功前缀，重试继续原批次；新修改不能混进原批次。`SyncTo` 可写出指定快照而不改变当前环境，`SyncStatus` 查询最新进度，`Operation` 查询原始文件操作结果。未知外部结果禁止自动重试，需可信调用方核对宿主并用 `Rebase` 显式重建基线。普通冲突也可以用此入口处理。

首版将同一环境的文件和管理操作串行化，外部同步期间也会等待；查询审计与同步进度仍可进行。不同环境可以并发运行。共享宿主目标必须使用同一个 `local.Target` 协调对象，并排除其他宿主并发写入；摘要/内容比较不能解决任意外部写入竞态。

`local` 当前仅支持 Unix，其他平台明确拒绝。写回使用 `os.Root`、临时文件和单文件替换，不承诺整批原子性、崩溃恢复或 POSIX 元数据保真。新建目录权限为 0700，写回文件为 0600。关闭 Target 由持有者负责。

## 快照、审计与配额

`Snapshot`、`Snapshots`、`Restore`、`Release` 管理文件快照，`Diff` 比较两个快照或快照与当前环境。恢复生成新版本，保留历史审计，检查当前资源身份和授权，不恢复已撤销资源；存在进行中的网络请求或未解决同步批次时拒绝恢复。当前默认工作目录在快照中不存在时也拒绝恢复。

恢复暂停自动同步；调用方可以显式 `Sync` 写出补偿变更，或通过 `ResumeSync` 恢复后续自动触发。恢复本身不改宿主文件，不回滚网络副作用。

`Events(after, limit)` 按单调序号读取操作结果，目录删除、重命名和恢复包含逐路径内容引用；`Content` 读取对应字节。`PruneEvents` 由可信控制层显式清理历史，过期游标返回 `ErrCursorExpired`。回收保留当前状态、快照、审计和同步仍引用的内容；事件保留期间可追溯中间版本。

`WithLimits` 配置内容与元数据预算、单文件大小、目录项数、事件数、快照数、幂等记录数及资源申请数。Bytes 使用保守的逻辑存储计费和操作预留，不是 Go 堆或进程 RSS 的硬上限；调用方输入、返回副本、临时分配和可信回调还会消耗内存。审计容量不足时拒绝新操作，无法再追加该次拒绝事件；不会接受没有权威审计的文件修改。不会自动溢写磁盘。

## 网络与动态资源

`httpgate.New` 默认没有允许规则。使用 `WithRules` 明确协议、主机、端口、方法，默认拒绝私有地址和跳转；解析结果经过检查后直接拨号到已验证地址，不使用环境代理。规则中的 Headers 由可信发送端注入；跳转逐跳授权，并丢弃原请求头，让新目标按自身规则重新注入。调用方负责按业务需要过滤响应中的敏感信息。

使用 `WithLimits` 设置请求/响应大小、并发和超时。`memory.WithNetwork(client)` 显式接入传输；无外部操作进行时可用 `SetNetwork` 替换，传入 nil 撤销。网络审计记录操作 ID、方法、目标协议/主机/端口、状态、大小和起止时间，不采集路径、查询参数、正文、请求头或原始传输错误。自定义 HTTPSender 属于可信代码，必须自行落实网络策略。外部效果不确定时不会自动重发。

`RequestResource` 只创建申请；可信控制层通过 `DecideResource` 批准或拒绝，再通过 `FulfillResource` 提供内容。批准后仍不可访问，直到提供成功。提供失败可以重试。审批可以由自动策略处理，不要求 UI 或人工；本包不发送通知、不调用模型。

## 生命周期与范围

`State` 查询生命周期与环境版本。`Close(ctx)` 拒绝新操作、取消外部请求并等待结束；超时后保持关闭中，可再次等待。不自动同步。关闭后仍可查询审计、内容、操作结果和同步状态。`Destroy(ctx, discard)` 释放已关闭环境的内存；存在未同步目标改动时，必须显式选择丢弃。

进程退出后环境丢失，即使宿主文件已经同步，也不能据此恢复完整环境历史。SDK 当前没有模型 Runtime、自动 Turn/Session 生命周期或原生程序执行器，应用负责把显式接口与自身生命周期组合。任意 Go 代码依然能绕过接口访问宿主；这个实现保障经过受控接口的操作，不是操作系统安全边界。
