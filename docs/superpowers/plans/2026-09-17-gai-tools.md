## 决策与证据

- Eino components/tool/interface.go、compose/tool_node.go：描述接口与可执行接口分离，运行配置接收 []tool.BaseTool。本地 HEAD 9d983b36。
- ADK-Go tool/tool.go、tool/functiontool/function.go：直接传入 []tool.Tool，Toolset 动态提供工具；泛型函数适配解码参数。本地 HEAD f7e16e0。
- Codex core/src/tools/registry.rs、router.rs：实现注册与模型可见描述分离，处理名称冲突。本地 HEAD b0659c5386。
- Aster pkg/tools/interface.go：工具工厂注册表、执行上下文注入 Sandbox；本次不照搬完整 Sandbox 暴露或静默覆盖注册。
- deepseek-harness packages/core/tools/src/index.ts：schema 与执行函数关联，调用上下文独立，取消采用协作语义，不强杀进程内回调。

以上为本地源码核查，不代表上游最新版本或运行验证。

Agent 是可保存的行为定义，因此保留 []ToolRef。实现由独立 Registry 持有，工具 ID 与模型可见 Name 分开，按 ID+Version 精确绑定，禁止隐式 latest 与重复注册。绑定后的 Set 仅包含 Agent 声明的工具，元数据复制并固定，实际回调是可信、可并发复用的宿主代码。

注册不授权；Set 默认拒绝执行，可信应用通过 WithAuthorizer 明确配置自动策略，不强制人工审批。调用顺序为参数基础检查、工具 Validate、授权、Execute。返回是否进入执行、实际工具版本、结果及执行状态；不自动重试、不自动持久化、不假装具有 exactly-once。同一 ToolCall 再次显式执行是另一次尝试。

JSON Schema 是模型描述，首版只检查它是 type=object 的有效 JSON；不声称通用 Schema 校验。每个工具必须提供 Validate。函数适配器支持显式 schema、Go 类型解码及必须提供的语义校验回调，不新增 schema 依赖或自动推导系统。

不在本次添加 MCP 客户端、动态工具发现、流式工具、原生命令或完整模型 Runtime。
